## Diagnóstico de la Causa Raíz

El problema está en **`orchestrator.ts`**, específicamente en el método `start()` y el loop `runAILoop()`.

### El Bug: `start()` se bloquea esperando `initialize()` del AI

```typescript

    // ...
    this.isRunning = true;  // ← se pone true ANTES de que el AI esté listo

        // ⚠️ ESTO ES BLOQUEANTE: espera a que el modelo se descargue COMPLETAMENTE
        await this.aiIntegration.initialize();  // ← puede tardar MINUTOS

        // Si el usuario hace "Skip & Use BabyBrain" durante esta espera,
        // forceBabyBrain() se ejecuta en el aiIntegration, PERO...
        // este await sigue esperando a que _doInitialize() termine.
        // _doInitialize() ya fue interrumpido por dispose(), pero la Promise
        // de initialize() queda colgada porque initPromise fue reseteada
        // en forceBabyBrain() sin resolver/rechazar la promesa original.

        this.events.onStatusChange?.("running");
        return;
    }

### El Problema en `ai-integration.ts`: `forceBabyBrain()` rompe la cadena de promesas

```typescript
// ai-integration.ts - forceBabyBrain()
async forceBabyBrain(): Promise<void> {
    if (this.engine && typeof this.engine.dispose === "function") {
        this.engine.dispose();  // ← dispone el engine que está descargando
    }
    this.engine = null;
    this.isInitializing = false;
    this.initPromise = null;  // ← RESETEA initPromise sin resolver la promesa anterior
    // ...
}
```

Cuando `forceBabyBrain()` hace `this.initPromise = null`, la promesa que `start()` está `await`eando (`this.aiIntegration.initialize()`) **nunca se resuelve ni se rechaza**. El `await` en `start()` queda colgado para siempre. Como `start()` nunca termina, `runAILoop()` nunca se ejecuta, y el botón "Start" queda inservible.

### El Segundo Problema: `_doInitialize()` no detecta que fue cancelado

Cuando `dispose()` se llama durante la descarga, el `pipeline()` de Transformers.js lanza una excepción. Pero `_doInitialize()` tiene un `catch` que intenta cargar BabyBrain:

```typescript

    // Intenta cargar BabyBrain como fallback
    const aiModule = await import("@bitcoinbaby/ai");
    await this.activateBabyBrain(aiModule);  // ← esto compite con forceBabyBrain()
}
```

Esto crea una **condición de carrera**: `forceBabyBrain()` y el `catch` de `_doInitialize()` ambos intentan crear un `BabyBrainEngine`. El que llegue segundo puede sobrescribir al primero o causar estados inconsistentes.

### 1. `ai-integration.ts` — Hacer que `forceBabyBrain()` cancele limpiamente la inicialización en curso

Agregar un `AbortController` para señalizar cancelación, y modificar `_doInitialize()` para que respete la señal de aborto.

// Agregar al inicio de la clase AIWorkIntegration:
private abortController: AbortController | null = null;

// Modificar _doInitialize():
private async _doInitialize(): Promise<void> {
    // Crear un nuevo AbortController para esta inicialización
    this.abortController = new AbortController();
    const signal = this.abortController.signal;

    try {
        // ... (código existente igual hasta el pipeline) ...

        await this.engine.initialize((progressData: AIProgressData) => {
            // ⚠️ NUEVO: Verificar si se abortó antes de notificar
            if (signal.aborted) return;
            // ... (resto del callback igual) ...
        });

        // ⚠️ NUEVO: Verificar si se abortó después de inicializar
        if (signal.aborted) {
            this.engine?.dispose();
            this.engine = null;
            return;
        }

        // ... (resto igual: detectar modelo, etc.) ...

    } catch (error) {
        // ⚠️ NUEVO: Si fue abortado, no hacer fallback a BabyBrain
        if (signal.aborted) {
            log.debug("Initialization aborted by user");
            return;
        }
        // ... (resto del catch igual) ...
    }
}

// Modificar forceBabyBrain():
async forceBabyBrain(): Promise<void> {
    // 1. Señalizar aborto para que _doInitialize() se detenga
    if (this.abortController) {
        this.abortController.abort();
        this.abortController = null;
    }

    // 2. Disponer el engine actual (cancela la descarga)
    if (this.engine && typeof this.engine.dispose === "function") {
        this.engine.dispose();
    }
    this.engine = null;

    // 3. Esperar a que cualquier initPromise pendiente se resuelva/rechace
    //    (ahora se resolverá rápido porque detecta el abort)
    if (this.initPromise) {
        try {
            await this.initPromise;
        } catch {
            // ignorar errores de la inicialización abortada
        }
    }

    // 4. Resetear estado
    this.isInitializing = false;
    this.initPromise = null;

    // 5. Activar BabyBrain limpiamente
    try {
        const aiModule = await import("@bitcoinbaby/ai");
        await this.activateBabyBrain(aiModule);
    } catch (error) {
        log.error("Failed to force BabyBrain activation", { error });
        this.engine = null;
        this.modelState = "error";
        this.notifyStatusChange();
    }
}
```
