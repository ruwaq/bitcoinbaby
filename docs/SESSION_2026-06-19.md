## 🔍 Problema Raíz: 3 Definiciones de "Bebé"

```
1. Baby (core/src/types.ts)          → Simple: id, name, state, level
2. GameBaby (core/src/game/types.ts) → Complejo: stats, progresión, evolución
3. BabyNFTState (bitcoin/src/charms) → On-chain: dna, bloodline, baseType, rarity
```

**3 stores separados:**
- `baby-store.ts` → "bebé gratis" (sin NFT)
- `nft-store.ts` → NFTs (sin game loop)
- `narrative-store.ts` → Historias AI (intenta unirlos)

**Hack en DashboardSection.tsx:** `buildNftStateFromBaby()` genera datos fake de un hash para que el NarrativeEngine funcione con bebés sin NFT.

## 🎯 Principio: 1 Bebé = 1 NFT

- El NFT ES el bebé. No hay "bebé gratis" separado.
- Mining = el bebé "aprende" (AI output → narrativa)
- BABTC = lo que el bebé "gana"
- Sin NFT = no se puede jugar (o modo limitado)
